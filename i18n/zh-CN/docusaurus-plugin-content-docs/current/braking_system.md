# 游戏中的制动系统概述

KR5000，原型为 Keio 5000 系；HR1100/1500，原型为 Kumoha 112/3/4/5 系；DC8500，原型为 Kiha 85 系。

## KR5000, HR1500: 电制动 / 直通管指令式空气制动，带自动空气制动备份

制动手柄控制制动级位（制动力大小）。

制动手柄给出制动级位。施加制动时，直通管压力随级位变化，作为空气制动指令；高速时优先使用电制动，发电灯亮，空气制动可能被减弱或切除，因此即使直通管压力保持，制动缸也可能风压较低。速度较低时 (\<10kph)，电制动切除，空气制动介入，直通管控制制动缸气压。制动管、均衡风缸常态保压。

紧急制动时，制动管急速排风，触发各车紧急制动；均衡风缸随之降压，直通管也排风/失效，空气制动施加最大制动。

## HR1100: 自动空气制动

本车型在现实中原型，制动手柄应为前段为直通空气制动，后段为自动空气制动；游戏中仅保留了自动空气制动部分的级位。（在缓解时，可以看到直通管气压的短暂上升。）

制动手柄控制均衡风缸充/放风。

制动手柄控制均衡风缸压力，均衡风缸控制制动管压力；制动位减压施加，保压位保持，缓解位升压缓解。直通管常态无压。

紧急制动时，制动管急速排风，触发各车紧急制动；均衡风缸随之降压，直通管也排风，空气制动施加最大制动。

## DC8500: 电控空气制动

本车压力表仅显示总风缸压力和制动缸压力。作为内燃动车组，本车无牵引电机发电/回生制动。制动手柄给出制动级位，由电子控制系统调节制动缸压力；不同制动级位对应不同目标制动缸压力，制动力随级位增加而增大。由于游戏中未显示其他压力，无法判断其具体实现。
