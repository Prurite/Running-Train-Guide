# Glossary

Glossary used in this book (Japanese–Romaji–English):

| Japanese | Romaji | English |
|----------|---------|---------|
| 信号 | Shin-gō | Signal (aspects) |
| 信号機 | Shin-gō-ki | Signal (device) |
| 中継信号 | Chu-kei-shin-gō | Repeaters (signal) |
| 進行 | Shin-kō | Proceed |
| 減速 | Gen-so-ku | Reduced speed |
| 注意 | Chū-i | Caution |
| 警戒 | Kei-kai | Restricted speed |
| 停止 | Tei-shi | Stop |
| 出発 | Shup-pa-tsu | Departure (signal) |
| 場内 | Jō-nai | Entrance (signal) |
| 閉塞 | Hei-so-ku | Blocks (railway) |
| 制限速度 | Sei-gen-so-ku-dō | Limit Speed |
| ハンドル | Han-do-ru | Handle (accelerate/brake) |
| ブレーキ | Bu-rē-ki | Brake |
| 停止位置 | Tei-shi-i-chi | Stop position |
| 入換 | I-re-kae | Shunting/maneuvering |

To avoid “oriental” language characters scare the hell out of many Westerners,
this is the only place you see their actual writing in Japanese, except for the
last chapter where I talked about *yubisashi* (指差し, pointing with a finger).
